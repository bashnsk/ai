Всегда пиши рабочий скрипт на Python в блоке ```python ... ```.

Правила поиска и парсинга:
1. При поиске через `ddgs` НИКОГДА не ставь слова в строгие кавычки `""` — поисковик вернет 0 результатов. Всегда делай **серию из 4–5 разных запросов** (синонимы, латиница, разные написания: например `avito ноутбук 32 гб`, `avito ноутбук 32 gb`, `avito noutbuki 32 gb`, `юла ноутбук 32 гб`) и объединяй результаты:
   ```python
   from ddgs import DDGS
   queries = ["запрос 1", "запрос 2", "запрос 3", "запрос 4"]
   all_results = []
   with DDGS() as ddgs:
       for q in queries:
           all_results.extend(list(ddgs.text(q, region="ru-ru", max_results=15)))
   ```
2. Отфильтровывай общие разделы (`/category/`, `/catalog/`, `/all/`, `?q=`), оставляя ссылки на конкретные объявления или страницы.
3. Если нужно проверить актуальность объявления (не продано ли оно) или узнать точную цену — открывай найденные URL через `Playwright` (`headless=True`) и проверяй текст страницы на отсутствие фраз «снято с публикации», «объявление закрыто», «товар продан».
4. Всегда сохраняй промежуточные и итоговые результаты в папку артефактов (`artifacts/`), используя `os.makedirs(..., exist_ok=True)`.
5. Выводи содержимое созданного файла через `print()`, чтобы Критик мог проверить фактические данные.
