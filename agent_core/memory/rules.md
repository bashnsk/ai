### Правила для предотвращения ошибок при парсинге и поиске:

1. **Установите все необходимые библиотеки перед запуском**.
2. **Обрабатывайте ошибки таймаута при выполнении DDGS запросов**.
3. **Не полагайтесь только на поисковые результаты, проверяйте содержимое страниц**.
4. **Используйте актуальные версии API с регулярными проверками**.
5. **Не сохраняйте данные без их предварительной корректности**.
6. **Обрабатывайте найденные объявления согласно фильтрам перед сохранением**.
7. **Не оставляйте заголовки без данных в final_report.md**.
8. **Используйте существующие атрибуты объектов, проверяйте их наличие**.
9. **Проверяйте содержимое файлов в папке артефактов после выполнения задания**.
10. **Избегайте использования устаревших методов и функций для парсинга и поиска**.
